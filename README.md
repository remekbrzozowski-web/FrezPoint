# FrezPoint

Gotowa strona statyczna z logo 07: 11 podstron, ciemna czerwień, projektowanie CAD, galeria i dane kontaktowe Radwanice.

Netlify: rozpakuj ZIP i opublikuj cały katalog zawierający index.html. Nie jest potrzebny proces kompilacji.

GitHub: skopiuj zawartość do dedykowanego repozytorium FrezPoint. Netlify można połączyć z tym repozytorium, ustawiając katalog publikacji na kropkę i pozostawiając komendę budowania pustą.

Formularz przygotowuje plik zapytania; nie wysyła danych. Zdjęcia są poglądowe. Motyw WordPress znajduje się w downloads/FrezPoint-WordPress.zip; nie działa na statycznym hostingu.
